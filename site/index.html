SAPHIR

Secure Acoustic Pairing for Heterogeneous Inter-agent Rendezvous.
From spoken dialogue to auditable structured collaboration over a low-bandwidth acoustic channel.

MCP/A2A/InterSAGE assume IP + HTTPS. SAPHIR covers the gap they leave: voice-only calls, PSTN-constrained trunks, offline / air-gapped rooms, noisy speakers.

Protocol in 60 seconds

  1. HELLO A→B: agent id, ephemeral DID, codecs, modes, nonce, timestamp (plaintext)
  2. WELCOME B→A: same + selected codec. Legacy peers offering no saphir-cbor-v1 are flagged — no silent downgrade to beeps.
  3. KEY1 / KEY2: 32B X25519 ephemeral pubkeys each way → HKDF-SHA256 → 32B ChaCha20Poly1305 session key (forward secrecy per pairing).
  4. TASK / RESULT: ChaCha(cbor({intent, slots, ontology, ts})), AAD binds sender, seq + nonce set rejects replays.
  5. Sidecar: every frame appended to JSONL with human summary + decrypted view.

Frame: u32be len ‖ CBOR({v, type, seq, sender, nonce, payload}), cap 200B. Measured: HELLO ~115B, WELCOME ~128B, KEY ~107–113B, TASK ~117–139B, RESULT ~126–139B — every frame fits one ggwave audible transmission.

Security properties (MVP)

  • ✅ Confidentiality + integrity for TASK/RESULT (AEAD, sender-bound AAD)
  • ✅ Forward secrecy per pairing (ephemerals discarded)
  • ✅ Replay rejection (seq window + nonce/ct set)
  • ✅ Downgrade flagging (no beeps with legacy peers)
  • ❌ Not yet: PKI-backed DID auth (break demonstrated in evals/mitm.py), MLS groups, ultrasound, DoS MAC — listed as future work.

Claim discipline: raw bytes are larger than English chars (CBOR + 16B auth tags + envelope). The saving is neural compute — no TTS/STT/LLM passes per turn; tone decode is ms of CPU. See docs/EVALUATION.md.

cd demo/web
python3 -m http.server 8080
# open http://localhost:8080              (role picker)
# two devices: ?role=caller + ?role=receptionist

Layout

  protocol.py   CBOR envelope, framing, 200B cap
  session.py    handshake state machine + AEAD messaging
  crypto.py     X25519 + HKDF + ChaCha20Poly1305
  channel.py    InMemory / Lossy(drop+corrupt) / ggwave probe
  agents.py     hotel-booking toy task (English vs structured)
  audit.py      JSONL sidecar log + human transcript
  metrics.py    cost/latency model (assumptions documented)

Project status

Functionally complete per its roadmap: baseline, handshake + crypto + audit + CLI demo, browser demo + lossy-channel sweeps, and the 6-page JAAMAS manuscript draft (paper/journal/) are done. Genuinely open items need hardware / new research: real-room measurements, DID PKI, MLS groups, schema-driven capability dictionaries, third-party audit, arXiv + JAAMAS submission (author actions).
